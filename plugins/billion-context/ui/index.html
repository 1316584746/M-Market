端口

它是一个本机代理：夹在 Agent 和模型 API 之间，把已经用过的对话压缩成摘要，让长会话不超出上下文窗口。安装用 npm install -g billion-context，需要本机有 Node.js / npm。

让 M-Harness 的模型走代理

到「设置 → 模型」，把下面某个提供方的 Base URL 改成「走代理的地址」即可（想恢复就改回原地址）。只有直接调用模型 API 的提供方（OpenAI 兼容 / Anthropic）能走代理；Codex、Cursor、Claude Code 这类外部 Agent 走它们自己的通道，代理管不到。
